================================================================
  STEP 1 — Clone โปรเจกต์ (branch: template-matching-ocr)
================================================================

  ** ใช้ branch "template-matching-ocr" สำหรับรันจริงกับปั๊ม **
  (ยังไม่ merge เข้า main)

  Clone ใหม่ทั้งเครื่อง:
    git clone https://github.com/sorawitsomjit/webcam_to_grafana.git
    cd webcam_to_grafana
    git checkout template-matching-ocr

  เครื่องที่ clone ไว้แล้ว (มี repo อยู่แล้ว แค่ต้องการ branch นี้):
    cd webcam_to_grafana
    git fetch origin
    git checkout template-matching-ocr
    git pull

  เครื่องที่มี branch นี้อยู่แล้ว แค่ต้องการโค้ดล่าสุด:
    cd webcam_to_grafana
    git checkout template-matching-ocr
    git pull

================================================================
  STEP 3 — ตั้งค่า config.py
================================================================

  เปิดไฟล์ config.py แล้วแก้ให้ตรงกับเครื่อง:

    CAMERA_INDEX = 0      หมายเลข webcam (0 = กล้องแรก, 1 = กล้องที่สอง)
                          ถ้าไม่รู้ลองเริ่มที่ 0 ก่อน
                          ** กล้องตัวเดียวกันนี้ถูกใช้ทั้ง live stream/snapshot
                             และ pressure OCR ไม่ต้องตั้งซ้ำ **

    SNAPSHOT_INTERVAL = 600   ความถี่ถ่ายภาพอัตโนมัติ (หน่วย: วินาที, ขั้นต่ำ 30)
                             600  = 10 นาที (default)
                             60   = 1 นาที (ใช้ตอนเก็บภาพไว้ debug OCR)

    PORT = 8080            port ของ web server
                          เปลี่ยนถ้า port นั้นถูกใช้อยู่แล้ว


    -- ตั้งค่ากล้อง (exposure/gain/white-balance) — สำคัญที่สุด --

    ** ต้องหาค่าใหม่ทุกครั้งที่เปลี่ยนกล้องหรือย้ายตำแหน่ง ค่าที่ให้มาใช้กับ
       กล้องตัวเดิมที่ TNO เท่านั้น **

    ทำไมถึงสำคัญ: ถ้าปล่อยให้กล้องปรับ exposure เอง (auto) จาก log จริงพบว่า
    ใช้เวลาถึง ~3 ชั่วโมงกว่าภาพจะนิ่งพอให้อ่านค่าได้ (อัตราสำเร็จ 0% -> 37%)
    แล้วพอมีอะไรมากระทบก็ร่วงกลับไป 0% ทันที จึงต้องล็อคเป็น manual

    วิธีหาค่า:
      python YOLO_test/camera_exposure_tune.py -c 1

      ปรับ trackbar จนตัวเลขบนจอ LCD คมชัดที่สุด แล้วกด 's'
      สคริปต์จะ print ค่าออกมาให้ copy มาใส่ตรงนี้ พร้อมบอกด้วยว่า
      กล้องรุ่นนี้ "รับ" ค่านั้นจริงไหม (บางรุ่นไม่รองรับ)

    CAMERA_MANUAL_EXPOSURE = -5     ใส่ None = ปล่อย auto (ไม่แนะนำ)
    CAMERA_GAIN = 0
    CAMERA_MANUAL_WB_TEMP = 3033
    CAMERA_BRIGHTNESS = 64
    CAMERA_CONTRAST = 64

    เคล็ดลับ: จอ LCD ตัวนี้ค่อนข้างมืด ถ้ามีไฟสว่างส่องจากข้างนอกจะยิ่งอ่านยาก
    ลองเอากระดาษบังแสงจากหลอดไฟด้วยจะช่วยได้มาก


    -- ตั้งค่า Pressure LCD OCR --
    กลุ่มนี้ใช้ค่า default ได้เลย ปรับเฉพาะที่จำเป็น:

    PRESSURE_OCR_INTERVAL = 20        ทุกกี่วินาทีให้ลองอ่านค่าหนึ่งครั้ง
    PRESSURE_OCR_ROI = None           ** ไม่ต้องแก้ตรงนี้ **
                                      ให้ไปลากกรอบบนภาพ live stream ในหน้าเว็บแทน
                                      (ปุ่ม "Select ROI") ค่าจะถูกเก็บแยกในไฟล์
                                      pressure_ocr_roi.json แก้ได้โดยไม่ต้อง
                                      restart app — เผื่อกล้องโดนชนขยับ
    PRESSURE_OCR_PRESET = "pressure_yolo"   ชื่อ preset แยกจาก preset ที่กรอกมือ

    -- Window voting --
    ระบบจะไม่บันทึกค่าทันทีที่อ่านได้ แต่จะอ่านซ้ำเรื่อยๆ แล้วสรุปครั้งเดียว
    ต่อหน้าต่างเวลา เอาค่าที่อ่านตรงกันมากที่สุด (กันการอ่านผิดแบบสุ่ม)

    PRESSURE_OCR_WINDOW = 600         ความยาวหน้าต่าง (วินาที) = 10 นาที
    PRESSURE_OCR_WINDOW_MIN_VOTES = 2 ต้องมีกี่ครั้งที่อ่านตรงกันถึงจะบันทึก

    ถ้าหน้าต่างไหนไม่มีค่าไหนตรงกันเลย จะข้ามไปเลยไม่บันทึก (ดีกว่าเดา)
    ดูสถานะได้ที่การ์ด "Votes this window" บนหน้าเว็บ


================================================================
  STEP 3.5 — Calibrate LCD templates  [ ไม่บังคับ — ข้ามได้ ]
================================================================

  ** ขั้นตอนนี้ข้ามไปก่อนได้ ระบบทำงานได้โดยไม่ต้องทำ **
  ถ้าไม่ทำ ระบบจะใช้ YOLO+EasyOCR ตามปกติ (แม่นยำน้อยกว่าแต่ใช้งานได้
  เพราะมี window voting ช่วยกรองอยู่แล้ว)

  ทำขั้นตอนนี้เมื่ออยากให้แม่นยำขึ้นมาก และมีเวลา calibrate

  ทำไมถึงช่วยได้:
    จอ LCD ของปั๊ม (Pfeiffer DCU002) ใช้ font แบบ dot-matrix ที่ OCR ทั่วไป
    (EasyOCR/Tesseract) ไม่เคยเทรนมา และเลข 0 มีขีดทแยงกลาง ทำให้อ่านผิดบ่อยมาก
    (จาก log จริง: 0 ถูกอ่านเป็น l/i/]/Z/I/O และ 3 ถูกอ่านเป็น S)
    วิธีแก้คือเทียบรูปตัวอักษรกับ template ที่ตัดมาจากจอตัวนี้โดยตรง

  วิธีทำ (ทำครั้งเดียว ถ้ากล้องไม่ได้ขยับมาก):

    1. ตั้ง ROI ก่อน (ลากกรอบบนภาพ live stream ในหน้าเว็บ ให้ครอบเฉพาะจอ LCD)

    2. รัน calibration tool — ใช้ snapshot ที่มีอยู่แล้วก็ได้ ไม่ต้องไปยืนที่ปั๊ม:

         python YOLO_test/build_lcd_templates.py --image snapshots/snapshot_XXXX.jpg

       หรือใช้กล้องสด:

         python YOLO_test/build_lcd_templates.py --camera 1

    3. ปรับ trackbar ให้เส้นกริดสีแดงตกร่องระหว่างตัวอักษร (1 ช่อง = 1 ตัวอักษร)
    4. กด 't' แล้วพิมพ์ข้อความที่เห็นในแต่ละบรรทัด เช่น "340: Pressure"
       ** ระวังเรื่องช่องว่างนำหน้า — บรรทัดค่าจะชิดขวา **
    5. กด 's' เพื่อบันทึก grid, กด 'q' ออก

  สำคัญ: ต้องเก็บ template ให้ครบเลข 0-9
    รอบเดียวมักได้ไม่ครบ (ค่า pressure ตอนนั้นมีแค่บางเลข) เครื่องมือจะบอกว่า
    ยังขาดตัวไหน ให้รันซ้ำกับ snapshot อื่นที่ค่าต่างออกไป template จะสะสมเพิ่มเรื่อยๆ

    ระหว่างที่ยังไม่ครบ ระบบจะ "ปฏิเสธ" การอ่านที่มีตัวอักษรไม่รู้จัก แทนที่จะเดา
    (ไม่ปล่อยค่าผิดเข้ากราฟ) แล้วถอยไปใช้ YOLO+EasyOCR แทนชั่วคราว

  หลังเพิ่ม template แล้วไม่ต้อง restart app — เรียก:
    curl -X POST http://localhost:8080/api/pressure_ocr/templates/reload


================================================================
  STEP 4 — รัน Flask App
================================================================

  Windows:
    .\venv\Scripts\activate
    python app.py

  Linux / macOS:
    source venv/bin/activate
    python app.py

  หน้าเว็บหลัก:  http://localhost:PORT
  ตัวอย่าง:      http://localhost:8080


  ----------------------------------------------------------------
  เช็คลิสต์หลังรันครั้งแรก (ทำตามลำดับ)
  ----------------------------------------------------------------
    1. เปิดหน้าเว็บ ดูว่าภาพ live stream ขึ้นไหม
       ถ้าไม่ขึ้น -> ลอง CAMERA_INDEX อื่น (0, 1, 2)

    2. ดูว่าตัวเลขบนจอ LCD ในภาพคมชัดพอไหม
       ถ้ามัว/สว่างเกิน/มืดเกิน -> กลับไป STEP 3 ปรับ exposure ใหม่

    3. กด "Select ROI" แล้วลากกรอบครอบเฉพาะจอ LCD
       (อย่าให้ติดสติ๊กเกอร์ "340 Pressure" ที่แปะข้างบนจอ กับโลโก้ PFEIFFER)

    4. รอดู 10-20 นาที ดูการ์ด "Votes this window" ว่าโหวตขึ้นไหม
       ถ้าขึ้นเรื่อยๆ = OCR อ่านได้ปกติ

    5. ** สำคัญ ** พอกราฟมีค่าแรกขึ้นมา ให้เทียบกับตัวเลขบนจอจริงด้วยตา
       ระวังเป็นพิเศษ: ค่าที่ผิดเป็น 10 เท่า หรือ 100 เท่า
       (เช่น จอขึ้น 4.6E+1 แต่กราฟขึ้น 4.6E+0)
       ถ้าเจอแบบนี้ให้แจ้งทันที — เป็นการอ่านชี้กำลังผิด ซึ่ง window voting
       กรองไม่ได้ เพราะมันผิดเหมือนกันทุกครั้ง

================================================================
  Endpoints ทั้งหมด
================================================================

  /                          หน้าเว็บหลัก (stream + gallery + pressure OCR)
  /video_feed                MJPEG live stream (มี overlay กล่อง OCR + ค่า pressure)
  /latest                    ภาพล่าสุด (JPEG)
  /snapshot/n/<N>            ภาพที่ N (0=ล่าสุด, 1=ก่อนหน้า, ...)
  /snapshots/<filename>      ไฟล์ภาพตาม filename
  /api/snapshots?limit=N     JSON list ของ snapshots
  /api/status                สถานะกล้องและระบบ
  /embed/stream              หน้า stream สำหรับเปิดใน browser
  /embed/snapshot            หน้า snapshot สำหรับเปิดใน browser
  /embed/gallery?limit=N     หน้า gallery สำหรับเปิดใน browser

  -- Pressure LCD OCR (YOLO) --
  /api/pressure_ocr/status         JSON สถานะล่าสุดของการอ่านค่า OCR
  /api/pressure_ocr/new_session    POST — เริ่ม session ใหม่ (archive ค่าเดิม
                                   ไปเป็น preset แยก ไม่ต้อง restart app.py)
  /embed/pressure_ocr              หน้าสรุปสถานะ OCR สำหรับฝัง Grafana


================================================================
  แก้ปัญหาเบื้องต้น
================================================================

  กล้องไม่ติด
    - ลอง CAMERA_INDEX อื่น (0, 1, 2)
    - ตรวจสอบว่าไม่มีโปรแกรมอื่นใช้กล้องอยู่

  Port ใช้ไม่ได้
    - เปลี่ยน PORT ใน config.py (เช่น 5050, 8080, 8888)
    - รัน app.py ใหม่หลังแก้

  Grafana ไม่แสดงภาพ
    - ตรวจสอบ IP และ PORT ใน HTML snippet
    - ตรวจสอบว่า app.py รันอยู่
    - Text panel ต้องเปิด HTML mode (disable_sanitize_html = true ใน grafana.ini)

  ติดตั้ง easyocr/ultralytics แล้ว cv2.imshow ใช้ไม่ได้ (GUI window ไม่เปิด)
    - แปลว่า opencv-python-headless ถูกดึงมาทับ opencv-python ตัวเดิม
    - แก้: pip uninstall -y opencv-python-headless
           pip install --force-reinstall --no-deps opencv-python==4.13.0.92
    - ป้องกันไว้ก่อน: ติดตั้ง torch (CPU-only) ก่อน requirements.txt เสมอ
      ตามขั้นตอนใน STEP 2

  รันครั้งแรกช้ามาก / ค้างตอนโหลด
    - รอบแรกที่รัน app.py มันจะโหลด YOLO model จาก Hugging Face
      (RoyRud1902/yolo11n-text) ต้องมีอินเทอร์เน็ต และใช้เวลาสักครู่
      ครั้งต่อไปจะเร็วขึ้นเพราะ cache ไว้แล้ว

  Pressure OCR ไม่ยอมอัปเดตค่า (badge ค้าง/ไม่ขยับ)
    - เครื่องนี้ไม่มี GPU เลยใช้เวลาราว 5-8 วินาที ต่อการอ่านหนึ่งครั้ง
      (PRESSURE_OCR_INTERVAL ปกติ) เป็นเรื่องปกติ ไม่ใช่ค้าง
    - เช็คที่ /api/pressure_ocr/status ว่า "connected": true หรือไม่
